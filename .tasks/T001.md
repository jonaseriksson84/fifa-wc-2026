# Task: Site-wide Recap live banner in root layout

## Context

SvelteKit 2 + Svelte 5 (runes) app on Cloudflare Workers — a WC 2026 prediction pool
with a sticker-album/newspaper visual identity (CSS custom properties in `src/app.css`:
`--paper`, `--ink`, `--accent`, fonts `--display`/`--headline`/`--body`/`--mono`).

The **Recap** is the post-tournament summary page at `/recap`. It becomes available the
moment the Final fixture has a `result` (see `src/lib/server/recap/recap.ts`, which
computes `available` inside `computeRecap`). Today the only discovery surface is a
foil-gradient banner on the leaderboard page (`src/routes/leaderboard/+page.svelte`,
class `recap-banner`, fed by `recapAvailable` from its `+page.server.ts`).

A UI prototype settled the design: the banner moves to the **root layout** so it shows
on every page, as a slim full-width "foil ribbon" strip rendered **above the masthead
header**. The winning prototype component is preserved at
`git show prototype/recap-banner-variants:src/lib/components/prototype/RecapLiveRibbon.svelte`
— read it; the production component should reproduce its markup/CSS essentially 1:1
(copy, foil conic-gradient background, shine sweep animation, reduced-motion and
mobile handling).

Read for style/interfaces before writing:
- `src/routes/+layout.svelte` and `src/routes/+layout.server.ts` (where the banner mounts)
- `src/routes/leaderboard/+page.svelte` + `+page.server.ts` (old banner to remove)
- `src/lib/server/recap/recap.ts` (availability logic lives here)
- `src/routes/layout.test.ts` and `src/routes/leaderboard/leaderboard.test.ts` (test style; both assert on source text of the svelte/ts files)

## Acceptance criteria

- `src/lib/server/recap/recap.ts` exports `recapAvailable(fixtures)` (typed against the existing fixture shape used by `computeRecap`; it must only require the fields it needs — at minimum `stage` and `result` — so the layout loader can pass a narrow select), and `computeRecap`'s `available` field is derived from it.
- Root layout shows the foil ribbon on all routes when the Final has a result, except on `/recap` itself; never shown when unavailable.

- Leaderboard page no longer renders its own recap banner and its loader no longer computes `recapAvailable`.
- `npm run typecheck` passes.
- Whole test suite passes: `npm test`.
